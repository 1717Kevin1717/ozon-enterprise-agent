# Demo Data

This directory contains **synthetic / mock examples only** for development and evaluation.

- `selection-policy-sample.csv` is a small example knowledge file.
- The main mock product dataset is generated by `backend/app/services/demo_dataset.py`.
- These files do **not** represent real Ozon market data or confidential enterprise data.

Do not place real customer, order, procurement, credential, or internal company data in this directory before publishing the repository.
